📚 Library Management System

A terminal-based Library Management System developed using C++17 as part of our BTech Computer Science and Engineering academic project.

📌 Project Overview

The Library Management System helps librarians manage books, members, book issuing, returns and overdue fines through a simple menu-driven terminal application.

It aims to make basic library operations easier, faster and more organized.

🎯 Objectives

- Manage book records efficiently.
- Register and manage library members.
- Issue and return books.
- Calculate overdue fines.
- Maintain borrowing history.
- Store records using file handling.

⚙️ Technologies Used

- Programming Language: C++17
- Data Structure: Custom Linked List
- STL: Standard Template Library
- File Handling: Text files
- IDE: Visual Studio Code

✨ Features

Librarian Module

- Add new books.
- Edit book details.
- Delete books.
- Search books by ID, title or author.
- View all available books.
- Register members.
- Issue and return books.
- Calculate overdue fines.
- Generate library reports.

Member Module

- View available books.
- Search for books.
- View personal borrowing history.

📖 Library Rules

- Maximum borrowing limit: 3 books per member.
- Fine: ₹5 per overdue day.
- Dates are entered in YYYY-MM-DD format.

🗂️ Project Files

- "LibraryManagementSystem.cpp" – Main C++ source code.
- "books.txt" – Book records.
- "members.txt" – Member records.
- "transactions.txt" – Issue and return records.
- "UML-Diagram.png" – UML class diagram.
- "Project-Report.pdf" – Project documentation.
- "Project-Presentation.pptx" – Project presentation.

▶️ How to Run the Project

1. Install a C++ compiler such as MinGW-w64.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Compile the program:

g++ -std=c++17 LibraryManagementSystem.cpp -o library

5. Run the program on Windows PowerShell:

.\library.exe
